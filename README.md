# blbruno cafe — Website

A beautiful, Apple-inspired landing page for an artisan coffee brand. Built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

🌐 **Live site:** [lbruno086.github.io/coffee-website](https://lbruno086.github.io/coffee-website)

---

## Features

- Full-screen hero with real photography
- Smooth scroll animations (fade-up on enter)
- Sticky nav with blur effect on scroll
- Menu grid with hover interactions
- Coffee origins section with country photos
- Visit section with café interior photo
- Email subscription CTA
- Fully responsive (mobile, tablet, desktop)

## Stack

| Layer | Tech |
|-------|------|
| Markup | HTML5 |
| Styles | CSS3 (custom properties, grid, flexbox) |
| Scripts | Vanilla JavaScript (IntersectionObserver) |
| Fonts | Inter via Google Fonts |
| Photos | Unsplash (free license) |

## Structure

```
coffee-website/
├── index.html    # Main page
├── styles.css    # All styles
├── script.js     # Scroll animations + interactions
└── README.md
```

## Running locally

Just open `index.html` in your browser — no build step needed.

```bash
open index.html
```
